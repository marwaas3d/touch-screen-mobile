# 🎨 Touch Draw App

A simple drawing application built using Kivy that allows users to draw on the screen using mouse or touch.

---

## 📌 Project Idea

When the user touches the screen:
- A **circle** is drawn at the touch position.
- A **line** starts and follows the movement.
- Each touch has its own **random color**.

---

## 🚀 Features

- Multi-touch support
- Random color per touch
- Smooth drawing experience
- Dark background UI

---
